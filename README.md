A standalone Node.js 22 GitHub-compatible forge submitted to [make.fun's GitHub forge bounty](https://make.fun/bounty/github-core-clone-01).

## Run

```sh
node main.ts
```

The server binds an ephemeral port, registers with the make.fun harness, and remains running until the suite reports completion.
